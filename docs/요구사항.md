## 1. 사용자 문제·Product Goal·성공 기준

| 항목 | 정의 |
| --- | --- |
| 사용자 문제 | 참가자는 관심 있는 IT/테크 컨퍼런스와 인기 세션 정보를 한곳에서 비교·검색하고, 한정된 좌석의 인기 세션을 공정하게 신청할 방법이 없어 신청 실패·중복 결제 같은 혼란을 겪는다. 주최자는 컨퍼런스별로 별도 시스템을 구축할 여력이 없어 세션 신청 접수부터 좌석 관리·정산까지 수기·개별 도구로 처리하며 비효율을 겪는다. 전체관리자는 여러 주최자·컨퍼런스가 한 플랫폼에 공존할 때 승인·과금·정산을 통합 통제할 수단이 없으면 신뢰할 수 있는 다중 임차 운영이 어렵다. |
| Product Goal | 참가자가 원하는 컨퍼런스와 세션을 안정적으로 검색·신청·입장할 수 있고, 주최자가 자신의 컨퍼런스를 독립적으로 운영·정산할 수 있으며, 전체관리자가 여러 주최자·컨퍼런스를 하나의 플랫폼에서 통합 승인·감사·정산할 수 있는 상태에 장기적으로 도달한다. |

### Release 성공 기준

- 참가자가 회원가입 후 컨퍼런스·세션을 검색하고 세션 정원 내에서 결제까지 완료해 QR 티켓을 발급받을 수 있다.
- 정원을 초과하는 동시 신청 요청이 몰려도 확정 신청 수가 세션 정원을 넘지 않고, 초과 인원은 대기열로 처리된다 (권한·소유권·거래 일관성).
- 주최자가 컨퍼런스를 등록 신청하고, 전체관리자 승인 후에만 참가자에게 공개되어 신청을 접수할 수 있다.
- 결제 실패·취소, 정원 초과, 미승인 컨퍼런스 접근 같은 실패 흐름이 정상 흐름과 함께 검증된다.

## 2. 대상 사용자·Release 범위

### 대상 사용자

| Actor | 목표·책임 |
| --- | --- |
| 방문자 | 회원가입 전 컨퍼런스·세션 목록·상세를 조회하고 참가 여부를 판단한다 |
| 참가자(Member) | 회원가입 후 세션을 신청·결제하고 QR 티켓으로 입장(체크인)한 뒤 후기를 작성하며, 필요 시 취소·환불을 신청한다 |
| 주최자(Organizer) | 이메일·사업자등록번호 인증을 거쳐 스스로 계정을 발급받아 자신의 컨퍼런스·세션을 등록·운영하고 정산 내역을 확인한다 |
| 전체관리자(ADMIN) | 컨퍼런스 승인·결제 정산·통합 통계·시스템 설정· 회원 조회를 통해 플랫폼을 운영한다 |

### 범위

| 구분 | 내용 |
| --- | --- |
| 현재 Release | 컨퍼런스·세션 조회·검색, 회원가입/로그인(연령대·직무 포함, 이메일 인증, 소셜 로그인), 비밀번호 재설정, 회원 탈퇴, 마이페이지 프로필 수정, 컨퍼런스 소개글 AI 요약, 세션 신청·결제·QR 티켓 발급, 세션 정원 초과 방지와 대기열(예상 대기시간 포함), 컨퍼런스 등록 신청→승인→운영, 세션 승인·반려, 신청 취소·환불(기한 내), QR 입장 체크인, 참석자 통계·후기 기반 AI 요약, 참석 후기 작성, 주최자 프로필 조회, 주최자 운영 현황·정산 내역 조회, 전체관리자의 컨퍼런스 승인·결제 정산 현황 조회, PG 연동 키 등록, 회원 조회 |
| 후속 Product Backlog 후보 | 스폰서 배너 노출 신청·과금(舊 VIP 배너), 계정/권한 감사 로그 조회, 다국어 콘텐츠 노출, 컨퍼런스 장소 카카오맵 좌표 연동 |

## 5. 업무 용어

| 업무 용어 | 제품에서 사용하는 의미 |
| --- | --- |
| 컨퍼런스(행사) | 주최자가 등록하는 신청 대상 IT/테크 행사 단위 |
| 세션(트랙) | 컨퍼런스 내에서 별도 정원으로 운영되는 발표·강연 단위 |
| 세션 정원 | 하나의 세션에 확정 가능한 최대 신청 수 |

| 홀드(Hold) | 결제 완료 전, 좌석·인원을 임시로 점유해 중복 판매를 막는 상태 |
| QR 티켓 | 결제 확정 후 발급되는 1회성 입장 인증 코드 |

| 정산 | 결제 완료 건을 기준으로 주최자에게 지급할 매출·수수료를 계산하는 절차 |
| 스폰서 배너 | 주최자가 과금하여 노출 순위를 높이는 광고 슬롯 (후속 후보, 舊 VIP 배너) |
| 계정 연동 | 서로 다른 인증 수단이 같은 이메일을 가리킬 때 하나의 계정으로 묶는 것 |
| AI 요약 | (참석자 통계·후기 요약) 세션 신청 시 응답된 연령대·직무 데이터, 실제 체크인(QR 사용) 기록, 참가자 후기를 종합해 주최자·방문자에게 제공하는 컨퍼런스 참석자 통계·평판 요약. 컨퍼런스 소개글을 요약하는 "소개글 AI 요약"과는 다르다 |
| 후기(Review) | 체크인 완료된 좌석이 있는 예약의 예약자가 세션 종료 후 자신의 예약(그룹포함)을 대표해 남기는 익명 텍스트 평가 |
| 주최자 프로필 | 한 주최자가 과거에 연 승인된 컨퍼런스 목록과 각 컨퍼런스의 AI 요약을 모아 보여주는 화면 |
| 소개글 AI 요약 | 주최자가 저장한 컨퍼런스 소개글 텍스트와 이미지를 분석해 미리 생성해 두는 요약. 목록·상세에서 참가자가 핵심 내용을 빠르게 파악하도록 돕는다 |
