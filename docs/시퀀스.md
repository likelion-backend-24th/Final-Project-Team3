### **Story 11 — 참가자가 결제를 완료한다 (`#72`)**

```mermaid
sequenceDiagram
    actor P as 참가자
    participant G as Gateway
    participant RS as Reservation-Service
    P->>G: POST /api/reservations/{id}/payment (processPayment)

            RS->>RS: headcount만큼 QR 티켓 발급

    P->>G: GET /api/reservations/{id}/qr-tickets (getQrTickets)
    G->>RS: GET /api/reservations/{id}/qr-tickets (getQrTickets)
    alt status = CONFIRMED
        RS-->>G: 200 [{ ticketId, code, used }]

    end

        RS->>RS: provider 단위 update-or-create, secretKey는 암호화 저장
        RS-->>G: 200 저장 완료(응답의 secretKey는 마스킹)
        G-->>SA: 200 등록 완료
    else 필수값 누락
        RS-->>G: 400
        G-->>SA: 400 재입력 요구
    end
```
