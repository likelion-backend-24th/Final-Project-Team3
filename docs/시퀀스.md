```mermaid
sequenceDiagram

    G->>CS: GET /api/conferences (listConferences)
    CS-->>G: 200 승인된 컨퍼런스 목록

    G->>CS: GET /api/conferences/{id} (getConference)
    CS-->>G: 200 상세 + 세션 목록
```

### **Story 2 부속 — Refresh Token으로 Access Token을 재발급한다 (Task 2-1 `#9`)**

```mermaid
sequenceDiagram
    actor P as 참가자·주최자
    participant G as Gateway
    participant MS as Member-Service
    P->>G: POST /api/auth/refresh (refresh)
    G->>MS: POST /api/auth/refresh (refresh)
    alt 정상 토큰(미폐기·미만료)
        MS-->>G: 200 새 Access+Refresh Token 발급(기존 토큰 rotate)
        G-->>P: 200 재발급 완료
    else 이미 폐기된(rotate된) 토큰 재사용
        MS->>MS: 해당 회원의 모든 Refresh Token 무효화
        MS-->>G: 401 세션 무효화
        G-->>P: 401 재로그인 요구
    else 만료·존재하지 않는 토큰
        MS-->>G: 401 인증 실패
        G-->>P: 401 재로그인 요구
    end
```
