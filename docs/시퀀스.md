```mermaid
        CS->>RS: GET /internal/sessions/attendee-checkin-stats?sessionIds=... (getAttendeeCheckinStats)
        RS-->>CS: 200 집계값(기존과 동일)
        CS-->>G: 200 저장된 요약 그대로 반환(Gemini 미호출)
        G-->>O: 200 통계+요약 표시
    else 소유자 확인, checkedInCount = 0
        CS->>RS: GET /internal/sessions/attendee-checkin-stats?sessionIds=...
        RS-->>CS: 200 { checkedInCount: 0 }
        CS-->>G: 200 { checkedInCount: 0, summaryText: "아직 체크인한 참석자가 없습니다." }(Gemini 미호출)
        G-->>O: 200 안내 문구 표시
    else 소유자 확인, checkedInCount 변동(신규 집계 필요)
        CS->>RS: GET /internal/sessions/attendee-checkin-stats?sessionIds=...
        RS-->>CS: 200 집계값(연령대·직무 분포)
        CS->>RS: GET /internal/reservations/reviews?sessionIds=... (getReviewsBySessionIds)
        RS-->>CS: 200 { reviews: [...] }(실패해도 reviews=[]로 폴백)
        CS->>AI: 집계 수치+후기로 1~2문장 요약 요청(Gemini generateContent)
        alt Gemini 응답 성공
            AI-->>CS: 요약 텍스트
            CS->>CS: conference_attendee_summary upsert
            CS-->>G: 200 통계+새 요약 반환
            G-->>O: 200 통계+요약 표시
        else Gemini 호출 실패·Timeout
            CS-->>G: 200 통계는 정상 + summaryText "요약 정보를 일시적으로 생성하지 못했습니다."
            G-->>O: 200 표시(요약만 대체 문구)
        end
    else Reservation-Service 집계 조회 실패·Timeout
        CS->>RS: GET /internal/sessions/attendee-checkin-stats?sessionIds=...
        RS--xCS: 오류
        alt 기존 캐시 있음
            CS-->>G: 200 기존 캐시 그대로 반환
            G-->>O: 200 이전 통계 표시
        else 캐시 없음
            CS-->>G: 503 RESERVATION_SERVICE_UNAVAILABLE
            G-->>O: 503 재시도 안내
        end
    end
```
