- 최초 화면설계 초안의 "신청 취소·환불"·"QR 입장 체크인"·"운영 현황 조회"·"정산 내역 조회"·"통합 정산 대시보드"는 모두 PLANNED 상태였으나, 현재는 각각 마이페이지(`/my`)·주최자 체크인(`/organizer/checkin`)·운영 현황(`/organizer/conferences/:id/operations`)·정산 내역(`/organizer/settlements`)·관리자 정산 대시보드(`/admin/settlements`) 화면으로 모두 구현 완료(DONE)됨.
- "세션 신청" 화면의 "동반자 정보 입력 미구현" 메모는 해소됨 — 9명 이하 개별 입력/10명 이상 일괄 입력이 `createHold` API와 함께 실제로 동작하며, 2026-09-28부터 본인(1번) 좌석은 마이페이지 프로필값으로 자동 채워진다.
- 대기열 화면은 2026-09-28 UX 개선으로: (1) 예상 대기시간을 "평균 결제 소요시간 × 순번"이 아니라 결제 대기(HOLD) 좌석의 만료 시각 기준으로 계산해 "결과 확인까지: 늦어도 약 N분"으로 표시, (2) 대기 중에는 결제 버튼을 숨기고 순번이 도달(HOLD로 승격)했을 때만 "차례가 왔어요!"와 결제 버튼을 노출, (3) 순번 조회가 404(대기열 이탈)가 되면 내 예약 목록을 다시 조회해 승격/취소/결제완료 중 실제 상태에 맞는 안내로 전환하도록 변경.
